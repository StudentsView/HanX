# Clean HanX GUI implementation plan

Goal: Align the portable Windows/Linux editor with the existing Mac ribbon and restrained palette, and show GUI warnings/errors/contextual instructions in dialogs rather than persistent panels. Preserve all editing, conversion, spreadsheet and AI functions.

Architecture: Keep AppKit on Mac and the existing Electron/native engine elsewhere. Use the Mac palette and tab/group vocabulary in Electron. Main-process notifications own errors and document warning deduplication; editable document content and normal status/counts remain in the canvas. System window chrome follows the OS.

Constraints:
- User requested the GUI specifically; do not modify CLI help/output or recreate a pkg.
- Do not replace the richer Mac editor with the portable editor or remove editing functions.
- No permanent warning/error banners, sidebar prose, local-processing slogan or instruction paragraphs.
- Popup once per relevant file/warning, not on each edit or render. Do not silently hide actual import/save warnings.
- Existing macOS UI is the layout reference. Keep OS-standard keyboard behavior.
- Synced project sources/ are read-only; actual source is /Applications/HanX-Source.

Tasks:
1. Native Mac: remove duplicated automatic format bar and nonessential static instructions; move actual document/PDF import notices into NSAlert, deduplicated per opened document.
2. Portable UI: use neutral Mac palette, tabbed ribbon, compact file controls, bottom worksheet tabs, slide thumbnails and contextual shape properties. Move supported editing controls into appropriate ribbon groups and preserve existing handlers. Remove persistent banners, sidebar instructions and formula-error lists (cell formula values remain data).
3. Main-process popup presenter: queued native warning/error/help dialogs, bounded text, deduplication per file. IPC clipboard and contextual help are explicit enums. Keep renderer sandbox and sender/frame validation.
4. Test notification behavior and existing native/portable editing, then inspect real Mac/Electron UI. Run Windows/Linux native GUI smoke via CI if practical. Update local app/source, and report remaining platform differences honestly. Do not create pkg unless asked.
